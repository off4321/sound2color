# 音や画像から色を探す

音声や画像、音の説明文をEmbeddingGemma 2でベクトル化し、単色画像の色見本と直接比較するサンプルアプリです。

> **この結果は色の正確な測定ではありません。**  
> モデルの埋め込み空間で近い候補を表示します。音と色の対応が常に人間の感覚と一致する保証はありません。

## 仕組み

1. 色見本を単色画像としてEmbeddingGemma 2の公式SentenceTransformers経路で768次元ベクトルにし、ChromaDBに保存します。
2. 音声はフィルターや周波数分割をせず、音声全体を同じモデルのマルチモーダル入力としてベクトル化します。同時に基本周波数（音高）・スペクトル重心（音色の明るさ）・スペクトルフラットネスを解析します。
3. 音声全体の埋め込みと単色画像の埋め込みを比較し、音高・スペクトル重心から推定した目標明度に近い色を再順位付けします。音高が明確な場合は音高を主な明度指標、スペクトル重心を補助指標にします。音高が明確でない場合はスペクトル重心を使います。
4. 音の説明文はモデル指定の `SearchQuery` タスクでテキスト埋め込みを作り、色見本画像と比較します。
5. 画像を登録した場合も、同じモデルで画像をベクトル化し、ChromaDBに保存します。

埋め込みはSentenceTransformersのモデル設定どおり平均プーリングと正規化を行います。再順位付けは埋め込みの順位を65%、音の明るさに合う色の明度を35%として組み合わせます。音高が高いほど目標明度が高くなる一般的な傾向を反映します。人が個々の音源を調整する必要はありませんが、結果が全員の色連想と一致する保証はありません。
画面の類似度は音声と画像のコサイン類似度です。明度調整後の順位とは別の値であり、確率や色差ではありません。
検索結果はRGB値や知覚的な色差の測定ではありません。
登録画像の表示色は画像全体の平均RGB値です。透明部分は白背景に合成して扱います。

## 起動方法

Docker と Docker Compose が使える環境で、プロジェクトのフォルダーから実行してください。

```bash
docker compose up --build -d
docker compose ps
```

アプリをブラウザーで開きます: <http://localhost:8501>

使用モデル: [`google/embeddinggemma-2` (Hugging Face)](https://huggingface.co/google/embeddinggemma-2)。
初回起動時に埋め込みサーバーがこのページのモデルファイルをダウンロードします。
モデルファイルはプロジェクト内の `data/models/` に保存され、次回以降は再利用されます。
Docker 内の保存先は `/models`（Hugging Face Hub のキャッシュ配下）です。
アプリは埋め込みサーバーのモデル読み込み完了後に起動します。
その後、色見本3600色を単色画像として埋め込み、DBに登録します。この処理にも時間がかかります。

## 使い方

1. 「画像を検索対象として登録」で PNG / JPEG / WebP 画像を選び、登録ボタンを押します。
2. 音声を使う場合は WAV / MP3 ファイルを選びます。画面上で再生して確認できます。
3. 「近い色を探す」を押すと、加工していない音声全体と単色画像の埋め込みを比較し、音高・音色に基づく明度調整も加えて候補を並べます。
4. 音声ファイルを使わない場合は、音の特徴を文章で入力して検索できます。

アプリの初回表示時に、検索用の3600色を各1件の画像埋め込みにして ChromaDB に登録します。公式推論方式に揃えるため、従来の色ベクトル用コレクションとは別のコレクションを使います。
画像を登録すると、その画像のベクトルも色見本と同じコレクションに保存されます。

## よく使うコマンド

```bash
# ログを見る
docker compose logs -f app multimodal-embedding-server vector-db

# コンテナを停止する（保存済みデータは残る）
docker compose down

# Dockerの名前付きボリュームを削除（data/ 内のDB・モデルは残る）
docker compose down -v
```

DBやモデルも削除したい場合は、Dockerを停止してからプロジェクト内の `data/chroma/` または `data/models/` を削除してください。

## 設定

- `MODEL_ID`: 埋め込みサーバーで使う Hugging Face モデル
- `EMBEDDING_SERVER_URL`: アプリから埋め込みサーバーへの接続先
- `CHROMA_HOST` / `CHROMA_PORT`: ChromaDB の接続先

現在の値は [`docker-compose.yml`](./docker-compose.yml) にあります。
`app/setting/setting.md` にある Pi 向けの設定は任意の開発補助機能で、アプリの起動には必要ありません。
